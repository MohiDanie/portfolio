# mdanaie.ir

Portfolio of Mohadese Danaie, served by GitHub Pages.

## Editing content
Edit everything at https://app.pagescms.org (sign in with GitHub, open MohiDanie/portfolio).
Every save is a commit to main; GitHub Pages republishes in about a minute.

- content/*.json: all text, in English and Persian
- images/: case-study and project images
- index.html: design and rendering only
- .pages.yml: editor configuration

Markers in text: {?text?} needs confirmation, {!text!} missing information.
Both are hidden unless Settings > Draft mode is on.
